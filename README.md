# CAVA Analytics DataLab

The CAVAanalytics Datalab brings the CAVA ecosystem together in a ready-to-use cloud environment that can be deployed with a single click.

It provides a computing infrastructure needed to access and process climate data directly, without requiring users to download or manage large datasets locally. With [CAVAanalytics](https://github.com/un-fao/CAVAanalytics) tools already available, users can run workflows, perform climate impact assessments, and generate visualizations with just a few clicks.
